# Full 6-Week C++ Curriculum (Professional Outline)

## Week 1: Foundations
- **Topics:** Hello World, variables (`int`, `double`, `char`, `bool`), `cin` / `cout`, arithmetic operators.
- **Output:** Simple console calculator.

## Week 2: Control Flow & Functions
- **Topics:** `if/else`, `switch`, `for`, `while` loops, function declaration/definition, parameters, return.
- **Output:** Number guessing game.

## Week 3: Arrays, Strings & Memory
- **Topics:** Static arrays, C-strings vs `std::string`, function overloading, pointer basics, references.
- **Output:** Grade averaging system.

## Week 4: OOP Basics
- **Topics:** Class design, public/private, constructors, destructors, `this` pointer.
- **Output:** Bank Account class with deposit/withdraw methods.

## Week 5: OOP Deep Dive
- **Topics:** Inheritance (`public`/`protected`), polymorphism (`virtual` functions), abstract classes, friend functions.
- **Output:** Shape hierarchy (Circle, Rectangle) with area calculation.

## Week 6: STL, File I/O & Capstone
- **Topics:** `std::vector`, `std::map`, iterators, algorithms (`sort`, `find`), `fstream` (read/write), `try`/`catch` exceptions.
- **Output:** Student Record Manager (CRUD app with persistent file storage).
