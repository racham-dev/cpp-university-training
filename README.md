# cpp-university-training
6-week professional C++ curriculum with weekly lesson notes, code examples, and a final capstone project.


`markdown
# 🎓 6-Week Professional C++ Training Curriculum

**Target Student:** University student (17 years old)  
**Goal:** From zero to intermediate C++ (STL, OOP, File I/O) with a final portfolio project.  
**Format:** Weekly 2.5-hour sessions + 1-hour lab.

## 📅 Quick Syllabus

| Week | Topic | Key Concepts |
| :--- | :--- | :--- |
| 1 | C++ Foundations | Syntax, Data Types, `cin`/`cout`, Operators |
| 2 | Control Flow & Functions | Loops, `if/else`, Functions, Scope |
| 3 | Arrays, Strings & Memory | Arrays, `std::string`, Pointers, References |
| 4 | OOP Basics | Classes, Objects, Constructors, Access Modifiers |
| 5 | OOP Deep Dive | Inheritance, Polymorphism, Virtual Functions |
| 6 | STL, File I/O & Capstone | `vector`, `map`, `fstream`, Exceptions, Student Manager |

## 🚀 How to Use This Repo
- Each week has a `/week-X/` folder with:
  - `lesson-notes.md` – Detailed instructor guide
  - `examples.cpp` – Live demo code
  - `homework.md` – Practice tasks
- The `/projects/` folder holds the final capstone project.

## 🛠️ Prerequisites
- A C++ compiler (g++ / clang++ / MSVC)
- Code::Blocks, VS Code, or any IDE
- Basic familiarity with computer usage (no prior coding required).
```
